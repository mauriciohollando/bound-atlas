# Style Bible — The Bound Atlas

Source of truth for **clear-line characters on painterly places**.  
AI generation must attach locked sheets; human curation gates every milestone.

## Domain for this slice

**Meridian / Bound Compact:** deep gold, ink-blue cloaks, wet stone grey, cinnamon warm lights.

## Never list

- Purple-on-white / purple-indigo UI chrome
- Glassmorphism, neon multi-shadows
- Soft Middle violet as brand (only diegetic weather, later chapters)
- Inter / Roboto / Arial as display
- Baking obligatory dialogue into images (text lives in MDX/HTML)
