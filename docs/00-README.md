# Interactive Experience — Index

Planning documents for turning **The Bound Maps** prose bible + chapters into a multimedia interactive graphic-novel website.

## Core thesis

**The site is a Bound atlas that can be unpicked.**  
Reading mode = sanctioned map. Exploration = Soft Middle. Clues are cartographic objects. Progress redraws the visitor’s personal atlas.
