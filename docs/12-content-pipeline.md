# 12 — Content Pipeline

## Canonical flow

```
Prose chapter (canon)
  → Beat sheet / interaction notes (matrix row)
  → Thumbnail storyboard (Huynh/Boat method)
  → Panel + establish art
  → Layer separation (parallax / motion)
  → Motion pass
  → Audio accents + beds
  → Branch/archive chips
  → Flag QA + spoiler QA
  → Ship section / chapter
```

## Roles (can be same person early)

| Role | Owns |
|------|------|
| Story | Prose canon, flag timing |
| Experience design | Matrix, toys, hub |
| Illustration | Characters, places, seals |
| Motion | Scroll sync, islands |
| Audio | Stems, silence |
| Engineering | Manifests, gates, perf |
| QA | Spoiler, a11y, device tiers |

## Chapter Definition of Done

- [ ] Spine readable with reduced motion + muted audio  
- [ ] ≥3 environmental tells from shot list  
- [ ] Flags set/required match clue doc  
- [ ] Optional branches ≤ act budget  
- [ ] Hub pin sensory line updated  
- [ ] Archive entries (if any) labeled true/false internally  
- [ ] Tier C fallback verified  

## Text adaptation rule

Site text ≠ dump full prose.  
Adapt like Boat: keep kernel + voice; let image carry.  
Full prose remains available as optional “novella mode” later if desired — not required for v1.
