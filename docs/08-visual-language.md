# 08 — Visual Language Guide

## Overall direction

**Clear-line characters on painterly places** — Exodus/Tintin readability for people; Wormworld density for world. Ink-wash accents for memory, storm, and Soft Middle (Boat kinship, not copy).

## Palette systems

| Domain | Palette | Notes |
|--------|---------|-------|
| **Meridian / Bound Compact** | Deep gold, ink-blue cloaks, wet stone grey, cinnamon warm lights | Safe, ceremonial |
| **Saltmere** | Tar black, citrus, green glass, harbor brass | Liminal sea |
| **Span** | Pale sealed light, ocean dark, rune glass | Sacred engineering |
| **Auric Haven** | Honey stone, silver monorail, cream+iron (Sable) | Beautiful trap |
| **Spine** | White, shale, thin blue shadow | Subtraction |
| **Temple** | Black glass, bone-bell, gold hairline inlays | Pre-history |
| **Hollowford / Kessari** | Red dust, silt brown, reed green, twin-water | Hinge |
| **Soft Middle / Unbound** | Storm violet-ash, wet-black ink, wrong star silver | Use sparingly |
| **Ashari Continuance** | Bone silk, resin dark, true-name bone-ink | Patient geometry |
| **Ledger** | Retired-seal gold (slightly green), pin chrome | Wrong official |

Avoid default AI purple-gradient UI chrome; Soft Middle violet is diegetic weather, not brand theme.

## Typography

| Use | Direction |
|-----|-----------|
| UI / chapter titles | Expressive display with cartographic DNA (not Inter/Roboto) — e.g. a sharp serif or custom ink-serif |
| Body / panel text | Highly readable humanist or book face; high contrast |
| Ashari script | Designed glyphs; never rely on real sacred scripts |
| Seals / stamps | Geometric Compact sun + filigree variants (live vs retired) |

## Character design notes

- **Theo:** undersized energy, ink fingers, rebellious hair — silhouette readable at scroll speed  
- **Mira:** tall, braid, compass charm catchlight  
- **Vesper:** charcoal coat, late smile (animate smile delay)  
- **Melk:** map-scrap coat; aging visible across appearances  
- **Age clarity:** Theo reads 14 in posture/scale vs 19s — important for tone  

## Panel & canvas grammar

- Default: Wormworld-like vertical flow with shared backgrounds  
- Establish shots may engulf panels (black or place-bleed)  
- Action: shorter panel stacks; chase = scroll acceleration cues (not forced)  
- Intimate rituals (letter, seal): fewer panels, more hold  

## Motion vocabulary

| Motion | Meaning |
|--------|---------|
| Banner / cloth parallax | Living city |
| Sway / jolt | Embodied danger (Boat) |
| Pencil slip | World refuses map |
| Seal glow pulse | Bound warmth |
| Screen tear / ridge birth | Illegal cartography |
| White vignette | Sensory cost (lost north) |
| Vein flicker | Soft Middle |

## UI chrome visual rules

- Prefer parchment, wax, brass, ink over glassmorphism  
- No multi-layer neon shadows  
- Wanted posters: slightly wrong lithography  

## Accessibility

- Text not only in image  
- Color never sole meaning (veins also animate / pattern)  
- Reduced motion: replace tears/sway with crossfades
