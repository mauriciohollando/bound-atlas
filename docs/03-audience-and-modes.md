# 03 — Audience & Modes

## Primary audiences

| Audience | Want | Mode default |
|----------|------|--------------|
| **Story-first readers** | HP-like journey, characters, payoff | Linear scroll, minimal toys |
| **Explorer / design audience** | Craft, interaction, Awwwards energy | Hub + side paths + set-pieces |
| **Lore diggers** | Soft Middle, seals, Ashari, posters | Archive branches + clue toys (gated) |
| **Return visitors** | New noticing | New poster rumors, seal inspector depth |

## Device tiers

| Tier | Target | Promise |
|------|--------|---------|
| **A — Desktop / powerful laptop** | Full scroll + WebGL islands + hub | Complete vision |
| **B — Modern tablet / mid phone** | Full comic + lighter parallax + simplified hub | Story complete, fewer 3D rituals |
| **C — Low-end / no WebGPU** | Static+CSS motion comic, no WebGPU scenes | Readable, paced, sounding |

Never block story on Tier A features.

## Experience modes

### 1. Story Mode (default)
- Chapter select or Continue  
- Vertical scroll comic  
- Optional autoscroll  
- Side-path prompts appear as diegetic “fold marks” / vault tabs — skippable  

### 2. Atlas Mode (hub)
- Illustrated / 2.5D map of New + Old Continents + Span  
- Unlocked pins only  
- Shows Soft Middle veins after story flags  
- Entry from ENTER and between chapters  

### 3. Survey Mode (tools)
- Seal inspector, folio overlay, twin-curve toy  
- Unlocked gradually (Juni / Vesper / letter beats)  
- Cannot bypass narrative gates  

### 4. Archive Mode (optional)
- Wanted posters, crow notes, Map Law scraps, Ashari market tags  
- Framed as Ministry / Continuance / merchant evidence  
- Some entries false on purpose (Ledger noise)

## Session lengths

| Session | Design for |
|---------|------------|
| 5–10 min | One set-piece or hub wander |
| 20–30 min | One full chapter scroll (Boat-scale) |
| 2–3 hr | Full Book 1 spine (may be multi-sitting; save Continue) |

## Accessibility modes

- Reduce motion (respect `prefers-reduced-motion`)  
- Mute / stems-only / full score  
- High-contrast text panels  
- Skip optional branches always available  
- Keyboard scroll + focusable side-path controls  

## Tone contract with audience

- Warm and wondrous first (Meridian), then bureaucratic dread, then mythic cost.  
- Never shame explorers for missing branches.  
- Never soft-lock story behind a puzzle; puzzles reward lore, not progression past Ch17 gates that are story-timed.
